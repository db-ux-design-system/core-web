# Migration (5.x.x) ➡ 6.0.0

## Renamed CLI executables

The `bin` executables for `@db-ux/mcp-server` and `@db-ux/agent-cli` have been renamed to use a consistent `db-ux-` prefix, avoiding generic names that could collide with other packages.

| Package             | Before       | After              |
| ------------------- | ------------ | ------------------ |
| `@db-ux/mcp-server` | `mcp-server` | `db-ux-mcp-server` |
| `@db-ux/agent-cli`  | `agent-cli`  | `db-ux-agent-cli`  |

### How to migrate

Update any scripts, MCP configurations, or shell commands that reference the old executable names:

```diff
- pnpm exec mcp-server
+ pnpm exec db-ux-mcp-server
```

```diff
- pnpm exec agent-cli
+ pnpm exec db-ux-agent-cli
```

For MCP configuration files (e.g. `.kiro/settings/mcp.json`, VS Code `settings.json`), update the `command` field:

```diff
{
  "mcpServers": {
    "db-ux": {
-     "command": "mcp-server"
+     "command": "db-ux-mcp-server"
    }
  }
}
```
