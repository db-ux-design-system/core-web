# Migration (5.x.x) ➡ 6.0.0

## DBStack: default height is now `auto` (removed unconditional `block-size: 100%`)

`DBStack` no longer forces `block-size: 100%` on every stack. The default height is now `auto`, so a stack sizes to its children instead of stretching to fill a definite-height parent. Two new properties, `width` and `height`, make the sizing explicit.

### Why

The unconditional `block-size: 100%` forced nested stacks to stretch to their parent's full height, creating empty space when the content was shorter. Making `auto` the default removes that whitespace; layouts that genuinely need a full-height stack now opt in with `height="full"`.

### What changed

<!-- markdownlint-disable MD060 -->

| Property | Values           | Default | Description                                                                                   |
| -------- | ---------------- | :-----: | --------------------------------------------------------------------------------------------- |
| `width`  | `full` \| `auto` | `full`  | `full` gives `inline-size: 100%`; `auto` uses `fit-content` so the stack shrinks to children. |
| `height` | `full` \| `auto` | `auto`  | `full` gives `block-size: 100%`; `auto` uses `fit-content` so the stack shrinks to children.  |

<!-- markdownlint-enable MD060 -->

### How to migrate

If a stack relied on the previous full-height behavior — most commonly column layouts that distribute content with `justifyContent`, cross-axis `alignment` rows, or column `wrap` — add `height="full"`:

```html
<!-- Before (5.x): implicitly stretched to the parent's full height -->
<DBStack direction="column" justifyContent="space-between">
	<!-- ... -->
</DBStack>

<!-- After (6.x): opt in to full height explicitly -->
<DBStack direction="column" justifyContent="space-between" height="full">
	<!-- ... -->
</DBStack>
```

Stacks that only wrap their content need no change — `auto` is now the default and matches that intent.

### Removed stylesheet entry point

The internal `stack-web-component.scss` (and its compiled `stack-web-component.css`) has been removed; its styles now live in `stack.scss`. If you imported the compiled file directly:

```text
@db-ux/core-components/build/components/stack/stack-web-component.css
```

switch to the component stylesheet instead:

```text
@db-ux/core-components/build/components/stack/stack.css
```
