# Switch

Schaltet eine Einstellung zwischen zwei Zuständen (ein/aus) mit sofortiger Wirkung um.

## Do

- Verwende Switch nur, wenn das Umschalten sofort wirksam werden soll
- Spiegle den neuen Zustand visuell wider und gib bei Bedarf leichtgewichtiges Feedback
- Verwende kurze, positiv formulierte Labels wie „Benachrichtigungen aktivieren"

## Don't

- Verwende keinen Switch in einem Formular, in dem Änderungen erst nach „Speichern" angewendet werden – nutze stattdessen Checkbox
- Verwende keine Labels mit Verneinungen wie „Nicht benachrichtigen", die beim Umschalten mehrdeutig werden
