# Select

Ermöglicht die Auswahl einer Option aus einer vordefinierten Liste über ein Dropdown.

## Do

- Verwende Select für eine Auswahl aus einer vordefinierten Menge, wenn der Platz begrenzt oder die Optionenzahl moderat ist
- Verwende kurze, eindeutige Options-Labels und eine logische Sortierung
- Stelle ein kurzes, spezifisches Label bereit, konsistent mit anderen Formularfeldern
- Verwende eine klare leere Option/Platzhalter bei Pflichtfeldern und validiere entsprechend
- Passe die Select-Breite an das Formular-Layout an und halte die Ausrichtung konsistent

## Don't

- Verwende Select nicht für Mehrfachauswahl oder wenn Nutzer:innen alle Optionen gleichzeitig vergleichen müssen – nutze stattdessen Radio
- Packe keine sehr langen Listen in ein einfaches Select ohne Suche – nutze stattdessen Autocomplete/Custom Select
- Wähle keinen riskanten Standard vor, der eine Zustimmung impliziert oder verbirgt, dass eine Auswahl nötig ist
