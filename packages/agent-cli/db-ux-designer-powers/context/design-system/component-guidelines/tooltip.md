# Tooltip

Kurze, kontextuelle Information bei Hover oder Fokus ohne Unterbrechung des Ablaufs.

## Do

- Verwende einen Tooltip, um einen Icon-Button oder abgeschnittenen Text zu erklären
- Verwende knappe Formulierung und einfache Sprache – ein kurzer Satz oder eine Phrase
- Löse bei Hover und Tastatur-Fokus aus; blende bei Blur/Leave/Escape aus
- Platziere Tooltips nah am Auslöser, ohne relevante Informationen zu verdecken

## Don't

- Setze keine Pflicht-Formularanweisungen oder kritische Informationen in einen Tooltip – nutze stattdessen Infotext oder Popover
- Verwende keine mehrzeiligen Erklärungen, Listen oder interaktive Inhalte in einem Tooltip
- Zeige Tooltips nicht nur bei Hover an – Tastatur-Nutzer:innen müssen sie ebenfalls erreichen können
