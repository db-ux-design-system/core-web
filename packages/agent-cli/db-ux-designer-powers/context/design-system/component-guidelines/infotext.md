# Infotext

Kompakte unterstützende Information oder Hinweise direkt im Interface, ohne den Ablauf zu unterbrechen.

## Do

- Verwende einen kurzen Satz, der die Bedeutung oder nächste Schritte dort verdeutlicht, wo Nutzer:innen ihn brauchen
- Fette sparsam nur wenige Schlüsselwörter – die Nachricht muss auch ohne Hervorhebung verständlich bleiben
- Platziere Infotext genau dort, wo die Entscheidung getroffen wird, direkt am relevanten UI-Element
- Verwende Warning/Critical nur bei echtem Risiko; erkläre, was zu tun ist
- Verwende Infotext in Formularen für Einschränkungen nahe am Feld, nicht als Ersatz für Label oder Validierung

## Don't

- Verwende keine langen Absätze oder mehrere Themen – Infotext fokussiert auf eine Aussage
- Verwende Warning/Critical-Styling nicht für neutrale Tipps oder zur visuellen Betonung ohne echte Dringlichkeit
- Verwende Infotext nicht als generellen Ankündigungsbereich, der weit vom beschriebenen Element entfernt steht
