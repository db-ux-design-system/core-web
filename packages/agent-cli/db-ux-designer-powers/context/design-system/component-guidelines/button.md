# Button

Löst Aktionen aus und bestätigt Entscheidungen. Leitet Nutzer:innen durch wichtige Aufgaben und Abläufe.

## Regeln

1. Button = Aktion (Zustand ändern), Link = Navigation. Nie verwechseln.
2. Pro Viewport maximal ein Brand-Button als stärkster CTA — sekundäre Aktionen mit schwächerer Variante.
3. Labels kurz, einzeilig, aktionsbeschreibend (z. B. „Speichern", nicht „Daten").
4. Horizontal nebeneinander ausrichten wenn Platz reicht.
5. Mindest-Trefferzone 24×24 px — benachbarte interaktive Elemente dürfen nicht überlappen.
6. Maximal ein Icon pro Button — Icon-Only immer mit Tooltip und `aria-label`.
