# Accordion

Ausklappbare Abschnitte zum Platzsparen und schrittweisen Anzeigen optionaler Details.

## Do

- Verwende Accordions für FAQs oder Detail-Inhalte, die Nutzer:innen bei Bedarf öffnen
- Verwende beschreibende Überschriften und halte sie scannbar
- Verwende einen einheitlichen visuellen Stil für alle Accordion-Items im selben Container
- Halte die Struktur flach und einfach

## Don't

- Verwende Accordions nicht, wenn Nutzer:innen alle Abschnitte gleichzeitig scannen oder vergleichen müssen
- Verwende keine vagen Überschriften wie „Information 1/2/3" oder „Mehr Details"
- Baue keine mehrstufigen Accordion-Bäume, die wichtige Informationen verbergen
