# Button

Löst Aktionen aus und bestätigt Entscheidungen. Leitet Nutzer:innen durch wichtige Aufgaben und Abläufe.

## Do

- Verwende einen primären Button, um die Hauptaktion hervorzuheben, und platziere sekundäre Aktionen mit geringerer Betonung daneben
- Setze den Brand-Button als stärksten CTA nur einmal pro Viewport ein – konkurrierende primäre Aktionen erschweren die Entscheidung
- Verwende knappe, einzeilige Labels
- Verwende maximal ein Icon pro Button; bei Icon-Only immer einen Hover-Tooltip anzeigen
- Richte Buttons vorzugsweise nebeneinander aus, wenn der Platz ausreicht
- Verwende standardmäßig automatische Breite; wechsle bei mobilen Layouts auf volle Breite
- Verwende einen Button für Aktionen, die den Zustand ändern, und einen Link für Navigation
- Stelle einen klickbaren Bereich von mindestens 24×24 px durch umgebenden Abstand sicher

## Don't

- Staple Buttons nicht vertikal, wenn horizontaler Platz vorhanden ist, und lass keine Inhalte über den Button hinausragen
- Platziere benachbarte Steuerelemente nicht im erforderlichen 24×24 px Zielbereich
