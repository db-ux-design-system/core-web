# Select

Ermöglicht die Auswahl einer Option aus einer vordefinierten Liste über ein Dropdown.

## Regeln

1. Für einfache Einzelauswahl ohne Suche ab 6 Optionen verwenden. Bei bis zu 5 Optionen [Radio](../radio/guidelines.md) nutzen. Bei Mehrfachauswahl, Suche oder Gruppierung [Custom Select](../custom-select/guidelines.md) oder [Checkbox](../checkbox/guidelines.md) verwenden.
2. **sollte** Options-Labels kurz, eindeutig und logisch sortiert.
3. Bei Pflichtfeldern eine klare leere Option oder einen Platzhalter anbieten, keinen riskanten Standard vorauswählen, der Zustimmung impliziert.
