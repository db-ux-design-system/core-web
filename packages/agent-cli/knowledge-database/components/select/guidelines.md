# Select

Ermöglicht die Auswahl einer Option aus einer vordefinierten Liste über ein Dropdown.

## Regeln

1. Für Einzelauswahl aus fester Menge bei moderater Optionenzahl verwenden. Bei sehr langen Listen [Custom Select](../custom-select/guidelines.md) nutzen, bei Mehrfachauswahl [Checkbox](../checkbox/guidelines.md) oder Custom Select.
2. Options-Labels kurz, eindeutig und logisch sortiert.
3. Bei Pflichtfeldern eine klare leere Option oder einen Platzhalter anbieten, keinen riskanten Standard vorauswählen, der Zustimmung impliziert.
