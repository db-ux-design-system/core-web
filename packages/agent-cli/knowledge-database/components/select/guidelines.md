# Select

Ermöglicht die Auswahl einer Option aus einer vordefinierten Liste über ein Dropdown.

## Regeln

1. Für Einzelauswahl aus fester Menge bei moderater Optionenzahl — bei sehr langen Listen Custom Select verwenden, bei Mehrfachauswahl Checkbox oder Custom Select.
2. Options-Labels kurz, eindeutig und logisch sortiert.
3. Klare leere Option/Platzhalter bei Pflichtfeldern — keinen riskanten Standard vorauswählen, der Zustimmung impliziert.
