# Textarea

Ermöglicht die Eingabe und Überprüfung längerer, mehrzeiliger Texte in Formularen und Dialogen.

## Regeln

1. Für mehrzeilige Texte verwenden, für kurze einzeilige Werte stattdessen [Input](../input/guidelines.md).
2. Sichtbares Label bereitstellen und konsistent zu anderen Formularfeldern platzieren.
3. Starthöhe an die erwartete Eingabemenge anpassen.
4. Essenzielle Anforderungen nie nur im Platzhalter unterbringen, er verschwindet beim Tippen.
5. Hilfshinweis und Fehlermeldung bei ungültiger Eingabe bereitstellen.
