# Stack

Layout-Komponente zur Anordnung von Elementen in vertikalem oder horizontalem Fluss mit konsistenten Abständen.

## Regeln

1. Gap-Property für Abstände verwenden — nie manuelle Margins an einzelne Items.
2. Richtung (Column/Row) basierend auf Layout und Inhaltsanforderungen wählen.
3. Wrap aktivieren wenn Overflow-Risiko besteht und Inhalte zugänglich bleiben sollen.
