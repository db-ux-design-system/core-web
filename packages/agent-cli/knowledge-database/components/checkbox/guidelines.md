# Checkbox

Ermöglicht die Auswahl einer oder mehrerer unabhängiger Optionen mit klarem Auswahlzustand.

## Regeln

1. Checkbox bei Mehrfachauswahl (0 bis n) verwenden, [Radio](../radio/guidelines.md) bei gegenseitigem Ausschluss (genau 1 aus n).
2. Labels positiv formulieren und den aktivierten Zustand beschreiben, keine doppelten Verneinungen.
3. Jede Checkbox-Gruppe braucht ein übergeordnetes Gruppen-Label für den semantischen Rahmen.
4. **sollte** Alle Optionen einer Gruppe einheitlich formulieren: gleiche Satzstruktur, gleiche Länge.
5. Checkbox verwenden, wenn die Änderung erst nach Absenden wirkt, [Switch](../switch/guidelines.md) bei sofortiger Wirkung.
