# Infotext

Kompakte unterstützende Information oder Hinweise direkt im Interface, ohne den Ablauf zu unterbrechen.

## Regeln

1. Genau dort platzieren, wo die Entscheidung getroffen wird — direkt am relevanten UI-Element.
2. Maximal ein kurzer Satz zu einem Thema — keine langen Absätze oder mehrere Themen.
3. Semantische Variante passend zu Kontext und Dringlichkeit wählen — nie zur rein visuellen Betonung missbrauchen.
4. In Formularen für Einschränkungen und Format-Hinweise nah am Feld nutzen — nicht als Ersatz für ein Label.
5. Sparsam fetten — die Nachricht muss auch ohne Hervorhebung verständlich bleiben.
