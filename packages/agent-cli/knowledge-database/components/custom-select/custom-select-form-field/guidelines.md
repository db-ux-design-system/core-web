# Custom Select Form Field

Eingabefeld-Subkomponente, die den Trigger zum Öffnen des Dropdowns darstellt und ausgewählte Werte anzeigt.

## Regeln

1. Label immer setzen — beschreibt klar, welche Auswahl erwartet wird.
2. Label Variant passend zu anderen Eingabe-Feldern wählen.
3. Ausgewählte Optionen müssen ohne erneutes Öffnen überprüfbar sein — Tags bei Mehrfachauswahl die häufig bearbeitet wird, Amount bei engem Platz (nur Mehrfachauswahl), Text bei Einzelauswahl.
4. Clear Selection Button anzeigen, um Auswahl rückgängig zu machen. Ausblenden, wenn Platz gering ist und wenig bearbeitet werden muss.
