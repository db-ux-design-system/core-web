# Tab Item

Einzelner klickbarer Tab innerhalb der Tab List — zeigt ein Label und optional zusätzliche Inhalte.

## Regeln

1. Labels kurz und beschreibend formulieren.
2. Slot gezielt nutzen — keine komplexen Inhalte im Tab selbst platzieren.
3. Zu lange Labels werden ausgepunktet — Tooltip zeigt den vollständigen Text bei Hover.
4. Kein Tab ohne zugehöriges Panel — jedes Tab Item muss genau einem Tab Panel zugeordnet sein.
