# Tab Panel

Inhaltsbereich, der angezeigt wird, wenn der zugehörige Tab ausgewählt ist — nur ein Panel ist gleichzeitig sichtbar.

## Regeln

1. Keine verschachtelten Tabs innerhalb eines Panels. Stattdessen Headings oder Sections im Panel nutzen.

## Zusätzliche Informationen

- Ein Panel kann beliebige Inhalte aufnehmen — Text, Medien, Formulare oder ganze Layouts. Die einzige Einschränkung sind verschachtelte Tabs.
