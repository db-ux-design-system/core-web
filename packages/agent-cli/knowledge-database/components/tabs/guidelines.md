# Tabs

Organisiert zusammengehörige Inhalte in separate Ansichten — Nutzer können zwischen Inhaltsbereichen wechseln, ohne die Seite zu verlassen.

## Regeln

1. Tabs nur für verwandte Inhalte auf derselben Hierarchieebene verwenden — kein Ersatz für Seitennavigation zwischen unzusammenhängenden Bereichen.
2. Immer nur ein Tab gleichzeitig aktiv — wenn Nutzer mehrere Inhaltsbereiche gleichzeitig sehen müssen, stattdessen Accordion verwenden.
3. Horizontale Orientierung für wenige Tabs, vertikale Orientierung bei vielen Items — so wird starker Overflow vermieden und der Großteil der Items ist jederzeit für die Nutzer sichtbar.
4. Bei `tabItemWidth: full` das `tabItemAlignment` bewusst setzen (`start`, `center`, `end`).
