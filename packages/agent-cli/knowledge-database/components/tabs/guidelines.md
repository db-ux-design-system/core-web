# Tabs

Organisiert zusammengehörige Inhalte in separate Ansichten — Nutzer können zwischen Inhaltsbereichen wechseln, ohne die Seite zu verlassen.

## Regeln

1. Tabs nur für verwandte Inhalte auf derselben Hierarchieebene verwenden, nicht als Ersatz für Seitennavigation zwischen unzusammenhängenden Bereichen.
2. Immer nur ein Tab gleichzeitig aktiv. Wenn Nutzer mehrere Inhaltsbereiche gleichzeitig sehen müssen, stattdessen [Accordion](../accordion/guidelines.md) verwenden.
3. **sollte** Horizontale Orientierung für wenige Tabs, vertikale Orientierung bei vielen Items. So wird starker Overflow vermieden und der Großteil der Items bleibt jederzeit sichtbar.
4. Bei `tabItemWidth: full` das `tabItemAlignment` bewusst setzen (`start`, `center`, `end`).
