# Radio

Ermöglicht die Auswahl genau einer Option aus sich gegenseitig ausschließenden Alternativen.

## Regeln

1. Radio bei gegenseitigem Ausschluss (genau 1 aus n) verwenden, [Checkbox](../checkbox/guidelines.md) bei Mehrfachauswahl.
2. Für 2–5 Optionen nutzen, die direkt vergleichbar sein sollen. Ab 6 Optionen stattdessen [Select](../select/guidelines.md) oder [Custom Select](../custom-select/guidelines.md) verwenden.
3. **sollte** Labels kurz, klar und eindeutig voneinander unterscheidbar formulieren.
4. Optionen vertikal stapeln mit einheitlichen Abständen innerhalb der Gruppe.
