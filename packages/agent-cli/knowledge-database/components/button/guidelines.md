# Button

Löst Aktionen aus und bestätigt Entscheidungen. Leitet Nutzer:innen durch wichtige Aufgaben und Abläufe.

## Regeln

1. Button = Aktion (Zustand ändern), [Link](../link/guidelines.md) = Navigation. Nie verwechseln.
2. Pro Viewport maximal einen Brand-Button als stärksten CTA einsetzen, sekundäre Aktionen mit einer schwächeren Variante.
3. Labels kurz, einzeilig, aktionsbeschreibend (z. B. „Speichern", nicht „Daten").
4. Horizontal nebeneinander ausrichten, wenn Platz reicht.
5. Mindest-Trefferzone 24×24 px sicherstellen. Benachbarte interaktive Elemente dürfen nicht überlappen.
6. Maximal ein Icon pro Button. Icon-Only-Buttons immer mit [Tooltip](../tooltip/guidelines.md) und `aria-label` versehen.
