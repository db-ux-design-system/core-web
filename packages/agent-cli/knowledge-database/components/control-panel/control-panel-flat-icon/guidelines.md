# Control Panel Flat Icon

Primäre Navigationsleiste für Desktop- und Mobile-Anwendungen innerhalb der Shell. Stellt gleichwertige Ziele als flache Icon-Navigation dar.

## Regeln

1. Flat Icon nur für gleichwertige Ziele auf oberster Ebene einsetzen. Flat Icon nicht einsetzen, wenn ein Ziel dominiert, es gewichtet alle Ziele gleich.
2. **sollte** auf Desktop höchstens zehn Navigation Items einsetzen, optimal bis zu sieben, längere Icon-Listen widersprechen dem schnellen Zugriff.

## Zusätzliche Informationen

- In Flat Icon lässt sich das Label ausblenden, sodass nur das Icon sichtbar bleibt. _(Example-Kandidat)_
- Der Flat Icon Slot ist auf Mobile technisch begrenzt: zwei bis vier Items mit Text, zwei bis sechs Items ohne Text.
