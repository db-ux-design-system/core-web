# Control Panel Meta

Flexibler Bereich im Control Panel für ergänzende, global relevante Inhalte.

## Regeln

1. Meta für ergänzende, niedrig priorisierte Inhalte verwenden, die global gelten – etwa Meta-Navigationslinks, Environment Labels oder rechtliche Hinweise. Keine primären Navigation Items oder hochpriorisierten Aktionen in Meta platzieren, der Bereich ist ergänzenden Inhalten vorbehalten, die die übrigen Bereiche des Control Panels flankieren.
