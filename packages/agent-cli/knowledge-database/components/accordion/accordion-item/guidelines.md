# Accordion Item

Einzelnes auf-/zuklappbares Element innerhalb eines Accordions — enthält eine Überschrift und ausklappbaren Inhalt.

## Regeln

1. Inhalt auf ein Thema pro Item beschränken — kein „Sammel-Panel" für unzusammenhängende Informationen.
2. `defaultOpen` nur setzen, wenn der Inhalt für die Mehrheit der Nutzer sofort relevant ist.
3. `disabled` nur verwenden, wenn es einen nachvollziehbaren Grund gibt (z. B. fehlende Berechtigung).
