# Drawer Header

Subkomponente für den oberen Bereich des Drawers — zeigt einen optionalen Titel, den Close-Button und ergänzende Inhalte.

## Regeln

1. Titel klar und kontextbezogen formulieren — Nutzer müssen sofort verstehen, was sie im Drawer bearbeiten, ansehen oder auswählen.
2. Ergänzende Aktions-Elemente nur platzieren, wenn sie direkt mit dem Drawer-Kontext zusammenhängen — keine losgelösten Aktionen im Header.
