# Link

Dient der Navigation zu anderen Seiten, Abschnitten oder externen Zielen.

## Regeln

1. Link = Navigation. Für Aktionen, die Zustände ändern, stattdessen [Button](../button/guidelines.md) verwenden.
2. Text-Link für Inline-Navigation innerhalb von Fließtext verwenden, die eigenständige Link-Komponente für standalone Navigation außerhalb von Fließtext.
3. Brand-Variante nur sparsam für einen hervorgehobenen Navigationslink einsetzen, nicht für mehrere Links im selben Kontext.
4. Externe Links kennzeichnen (Icon) und Verhalten (neuer Tab) klar kommunizieren.
