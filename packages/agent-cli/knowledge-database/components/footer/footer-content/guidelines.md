# Footer Content

Oberer Bereich des Footers für sekundäre Navigation und weiterführende Inhalte.

## Regeln

1. In `Children` nur sekundäre, weiterführende Inhalte platzieren, keine Primärnavigation abbilden, die gehört in das [Control Panel](../../control-panel/guidelines.md).
2. **sollte** bis zu sieben Links einzeilig anordnen. Bei mehr als sieben Links die Links inhaltlich gruppieren, damit die Zeile nicht unübersichtlich wird.
3. Bei gruppierten Links **sollte** jede Gruppe mit einer eindeutigen Überschrift versehen werden.

## Zusätzliche Informationen

- Footer Content nimmt neben sekundärer Navigation auch nicht-navigatorische Inhalte auf, etwa Unternehmensinfos, Zahlungsarten oder Social-Media-Links. Welche davon eingesetzt werden, ist keine Regel, sondern eine Gestaltungsoption. _(Example-Kandidat)_
- Rechtliche Pflichtangaben liegen nicht in Footer Content, sondern in [Footer Meta](../footer-meta/guidelines.md).
