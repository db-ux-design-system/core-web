# Footer Meta

Unterer Bereich des Footers für Copyright-Hinweis und rechtliche Links.

## Regeln

1. In `Children` nur die Links platzieren, zu denen die Anwendung rechtlich verpflichtet ist. Keine werblichen oder navigatorischen Inhalte darüber hinaus.
2. Den Copyright-Hinweis nicht leeren, wenn die Anwendung rechtlich zur Angabe eines Rechteinhabers verpflichtet ist. Ansonsten **kann** er weggelassen werden.
