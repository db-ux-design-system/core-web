# Footer

Unterer Bereich im Layout mit sekundärer Navigation, rechtlichen Links und Meta-Informationen.

## Regeln

1. Footer nur einmal pro Seite einsetzen, keine zweite Instanz auf derselben Seite ergänzen.
2. Footer nicht in einem schmaleren Container verschachteln, er erstreckt sich immer über die volle Breite des Contentbereichs.
3. Footer Meta nicht weglassen, wenn die Anwendung zur Angabe rechtlicher Informationen verpflichtet ist. Welche Inhalte das konkret sind, regelt [Footer Meta](footer-meta/guidelines.md).

## Zusätzliche Informationen

- Footer Content und Footer Meta werden unabhängig voneinander befüllt: ohne sekundäre Navigation entfällt Footer Content, ohne rechtliche Pflichtangaben entfällt Footer Meta. _(Example-Kandidat)_
- Der Footer liegt im End Slot von [Shell Content](../shell/shell-content/guidelines.md) und scrollt dort je nach Scroll-Verhalten mit.
