# Transition

Tokens mit Zeitangaben und Bezier-Kurven für Animationen und Übergänge.

## Regeln

1. **sollte** Kleine Elemente → schnelle Duration; große Elemente → langsame Duration.
2. `functional` für Standard-UI-Übergänge, `emotional` für markenbetonte Animationen.
3. `show` zum Einblenden, `hide` zum Ausblenden.
4. Straight-Tokens verwenden, wenn Duration + Timing zusammen als transition-Shorthand gebraucht werden.
