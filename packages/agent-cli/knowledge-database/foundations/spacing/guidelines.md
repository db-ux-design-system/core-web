# Spacing

Tokens für Rhythmus und Abstände im Layout sowie innerhalb von Komponenten.

## Regeln

1. Fixed-Spacings für Abstände verwenden, die unabhängig von der Bildschirmgröße gleich bleiben.
2. Fixed-Spacings innerhalb von Komponenten und Modulen einsetzen, um eine einheitliche interne Struktur sicherzustellen.
3. Responsive-Spacings für Abstände verwenden, die sich an die Bildschirmgröße anpassen.
4. Responsive-Spacings zur Trennung größerer Layoutbereiche einsetzen, zum Beispiel zwischen Sections, Modulen oder Seitenbereichen.
5. Spacings verhalten sich adaptiv. Weitere Details befinden sich in der _principles/adaptive-density.md
