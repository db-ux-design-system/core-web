# Spacing

Tokens für Rhythmus und Abstände im Layout sowie innerhalb von Komponenten.

## Regeln

1. `spacing-fixed`-Tokens für Abstände verwenden, die unabhängig von der Bildschirmgröße gleich bleiben.
2. `spacing-fixed`-Tokens innerhalb von Komponenten und Modulen einsetzen, um eine einheitliche interne Struktur sicherzustellen.
3. `spacing-responsive`-Tokens für Abstände verwenden, die sich an die Bildschirmgröße anpassen.
4. `spacing-responsive`-Tokens zur Trennung größerer Layoutbereiche einsetzen, zum Beispiel zwischen Sections, Modulen oder Seitenbereichen.
5. `spacing`-Tokens verhalten sich adaptiv. Weitere Details befinden sich in der Datei [Adaptive Density](../_principles/adaptive-density.md).
