# Sizing

Konsistente Größen für interaktive Elemente und Container.

## Regeln

1. Sizing Tokens geben Elementen eine klar definierte Größe, die sich nicht an die Bildschirmgröße anpasst aber sich adaptiv verhält. Weitere Details befinden sich in der principles/adaptive-density.md
2. Für interaktive Elemente eine Klickfläche von mindestens 24x24px sicherstellen.
