# Border Width

Linienstärken für Umrandungen, Trennlinien und interaktive Zustände.

## Regeln

1. Linienstärken ausschließlich über `border-width`-Tokens setzen, nie über feste `px`- oder `rem`-Werte.

## Zusätzliche Informationen

- Die Core-Komponenten belegen die Skala wie folgt: `3xs` für Umrandungen und Trennlinien, `2xs` für Fokus-Outlines, `xs` für Auswahl-Indikatoren.
