## HTML

Use `.db-footer-meta` as the secondary visual area inside a native `.db-footer`. Copyright text is optional.

```html index.html
<footer class="db-footer">
	<div class="db-footer-meta">
		<div class="db-footer-content-container">
			<div class="db-footer-meta-inner">
				<p class="db-footer-copyright">© Example Company</p>
				<nav aria-label="Legal navigation">...</nav>
			</div>
		</div>
	</div>
</footer>
```
