## Web Components

For general installation and configuration take a look at the [wc-core-components](https://www.npmjs.com/package/@db-ux/wc-core-components) package.

### Load components

```js main.js
// main.js
import { defineCustomElements } from "@db-ux/wc-core-components";
defineCustomElements();
```

### Use component

```html index.html
<!-- index.html -->
<db-button variant="brand">Button</db-button>
```
