# Getting Started

This Storybook contains the technical documentation of the DB UX Design System:

- **Foundations**: how to include and use colors, densities, font sizes, variables and icons, plus IDE support, performance, browser support and the test table (which tests and audits exist per component). Design guidelines for the same topics are on the [Design System Platform](https://design-system.deutschebahn.com/documentation/foundation).

- **Components per framework** (React, Angular, Vue, Web Components, HTML): a **Getting Started** page per framework that links its setup article, and for every component an **Overview** page with usage, examples with code, properties, accessibility and migration.

Use the version dropdown next to each framework in the sidebar for earlier releases. The examples are shown in Light Mode. To check Dark Mode, open a framework Storybook on its own and add `&globals=mode:dark` to the URL.

Installation, styles and the theme are explained step by step on the [setup pages of the Design System Platform](https://design-system.deutschebahn.com/documentation/get-started). Guides across components – router links, form validation, testing your application, your own components and backdrops – are in [Learn on the Design System Platform](https://design-system.deutschebahn.com/documentation/learn).
