# Getting Started

This Storybook contains the technical documentation of the DB UX Design System:

- **Foundations**: how to include and use colors, densities, font sizes, variables and icons, plus IDE support, performance and browser support. Design guidelines for the same topics are on the [Design System Platform](https://design-system.deutschebahn.com/documentation/foundation).
- **Components per framework** (React, Angular, Vue, Web Components, HTML): every component has an **Overview** page with usage, examples with code, properties, accessibility and migration.

Use the version dropdown next to each framework in the sidebar for earlier releases. The light/dark mode switch is in the toolbar of each framework Storybook when you open it on its own; this combined view does not pass it on.

Installation, styles and the theme are explained step by step on the [setup pages of the Design System Platform](https://design-system.deutschebahn.com/documentation/get-started).
